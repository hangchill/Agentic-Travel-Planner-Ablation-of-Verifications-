# R3 vs R1: scope ladder effect by round window

Generated by `test_result_analysis/R3/R3_VS_R1_scoping_effect.py`. Do not edit by hand; rerun the script.

Aim: show what R3's scope widening adds over staying at slot scope. R1 edits only the flagged slots in every round; R3 also uses slot scope in rounds 1-2, then widens to day scope (rounds 3-4) and plan scope (rounds 5-6). Rounds 1-2 compare two slot-scope strategies (R3 can also unlock bookings, and the prompts differ); rounds 3-6 show the effect of the widening.

Methods: R1 (always slot); R3 (slot → day → plan). All values use the benchmark scoring (eval_exp functions, named places in English). Change and net values compare with the column before. The runs start from different initial plans, so compare the changes, not the levels.
